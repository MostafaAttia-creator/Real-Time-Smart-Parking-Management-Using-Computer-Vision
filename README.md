# 🚗 Smart Parking Slots Detector and Tracking

A Computer Vision project for **real-time parking slot detection and tracking** using **YOLO11**, **ByteTrack**, **OpenCV**, and **Streamlit**.

The system detects parking slots from images and videos, classifies each slot as **Occupied** or **Free**, tracks occupied slots over time, calculates parking duration, and displays live parking statistics through an interactive Streamlit interface.

---

## ✨ Features

* 🚗 Parking Slot Detection
* 🎯 Real-Time Tracking using ByteTrack
* ⏱ Parking Duration Counter
* 🟥 Occupied Parking Counter
* 🟩 Free Parking Counter
* 📊 Occupancy Percentage
* 🖼 Image Detection
* 🎥 Video Detection
* 📂 Upload Images and Videos directly from the Streamlit interface
* 💻 Interactive Streamlit Application

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/MostafaAttia-creator/parking-slots-detector-and-tracking.git
```

Navigate to the project folder:

```bash
cd parking-slots-detector-and-tracking
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

---

## 🎥 How to Use

1. Launch the Streamlit application.
2. Upload an image or a video from your computer.
3. Click **Start Detection**.
4. The system will automatically:

   * Detect parking slots.
   * Classify them as **Occupied** or **Free**.
   * Track occupied parking slots.
   * Calculate parking duration.
   * Display real-time parking statistics.

---

## 📊 Output

The application displays:

* Occupied Parking Slots
* Free Parking Slots
* Total Parking Slots
* Occupancy Percentage
* Parking Duration for each tracked occupied slot
